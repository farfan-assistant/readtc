# Changelog

## [0.1.0] — 2026-02-16

### Added
- Initial MVP release
- Chrome extension (Manifest V3) with content script and popup
- Auto-detection of legal document pages (T&C, Privacy Policy, EULA, etc.)
- One-click AI-powered analysis via OpenAI-compatible API
- Risk level assessment (low/medium/high)
- Structured output: summary, red flags, key points, rights, data privacy, costs
- Red flag detection for concerning clauses
- Copy-to-clipboard as Markdown
- Settings page for API key, model, and base URL configuration
- Dark theme UI
- Badge notification on detected legal pages
- Support for OpenAI, OpenRouter, and local LLM endpoints
- Context menu: right-click selected text to analyze
- Keyboard shortcut: Ctrl+Shift+T (Cmd+Shift+T on Mac)
